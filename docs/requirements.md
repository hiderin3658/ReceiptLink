# ReceiptLink 要件定義書

> レシート写真を撮るだけで家計簿が完成するアプリ。

- 作成日: 2026-05-09
- バージョン: 1.0
- ステータス: ヒアリング完了・確定

---

## 1. プロジェクト概要

### 1.1 背景
- 紙のレシートを溜めて手書き／表計算ソフトで集計するのが手間。
- 既存の家計簿アプリは多機能すぎて学習コスト・継続コストが高い。
- 「撮るだけ」で記録が完了し、月次の使い過ぎが直感的に分かるシンプルなアプリが欲しい。

### 1.2 コンセプト
**「レシート写真を撮るだけで家計簿が完成する」スマホ完結型シンプル家計簿。**

### 1.3 由来
本アプリは姉妹アプリ [OkazuLink](legacy/design.md)（料理・栄養管理アプリ）から、共通利用可能な以下の部分のコードを継承して開発する:

- Google OAuth + Supabase 認証
- レシート画像のアップロード（Supabase Storage）
- Gemini API によるレシート OCR (`extract-receipt` Edge Function)
- 商品リスト編集 UI

詳細は [`receipt-scan-spec.md`](./receipt-scan-spec.md) 参照。

## 2. ターゲットユーザー・利用シーン

### 2.1 想定ユーザー
- **主ユーザー**: 依頼者本人（単独利用を想定）
- 想定属性: 紙レシートを発行されることが多い日常生活を送っている個人
- 将来拡張: 世帯メンバー（配偶者など）の追加に対応できる構造を確保（実装は後回し）

### 2.2 利用シーン
| シーン | デバイス | 主操作 |
|---|---|---|
| 買い物直後（外出先） | スマホ | レシート撮影 → OCR → 確認 → 保存 |
| 家での記録（手入力） | スマホ | 「支出を追加」で品目入力 |
| 月末・月初の振り返り | PC | 月次レポート閲覧、CSV エクスポート |
| 固定費（家賃・サブスク等）の登録 | PC または スマホ | 設定画面でテンプレ登録、月次で自動計上 |
| 管理タスク（カテゴリ追加など） | PC | 設定画面で管理 |

### 2.3 公開範囲・アクセス制御
- **email ホワイトリスト制**（`allowed_users` テーブル）
- 許可された email のみログイン・利用可能
- ロール: `admin` / `user` の 2 種類
  - **admin**: 依頼者本人。ホワイトリスト管理 + カテゴリマスタ編集 + 自分の家計簿入力
  - **user**: 追加された世帯メンバー等。自分の家計簿データの登録・閲覧・編集のみ

## 4. 非機能要件

### 4.1 性能
- レシート OCR レスポンス: Flash モデルで 8 秒以内（フォールバック含めて 20 秒以内）
- 履歴一覧の初期表示: 1 秒以内（最新月、20 件程度）

### 4.2 セキュリティ
- Supabase Row Level Security (RLS) で各ユーザーが自分のデータしか読み書きできないことを担保
- ホワイトリスト未登録ユーザーは UI に到達しない（API 側でも 403 を返す）
- レシート画像は Supabase Storage のプライベートバケット（署名付き URL での閲覧のみ）
- API キー類はクライアント未公開（Server Action / Edge Function 経由のみ）

### 4.3 ユーザビリティ
- スマホファースト（縦持ち想定、片手操作が可能）
- PC でも崩れないレスポンシブ
- レシート撮影 → 保存まで最短 5 タップ

### 4.4 可用性
- ホスティング: Vercel + Supabase Cloud（無料枠運用前提）
- バックアップ: Supabase の自動バックアップに依存（個人運用のため別途取得は不要）

### 4.5 国際化
- 日本語のみ対応（UI / OCR / レシート想定）

## 5. 制約事項

### 5.1 期間
- **MVP リリース目標: 1〜2 週間以内**
- 上記から逆算してスコープを厳選

### 5.2 コスト
- ホスティング: Vercel Hobby / Supabase Free 枠で運用
- AI: Gemini 3 Flash 中心（Pro はフォールバック時のみ）。月次 AI コストは ¥1,000 以内が目安

### 5.3 デバイス
- 対象: モダンブラウザ（Chrome / Safari 最新版）
- スマホ OS: iOS 16+ / Android 12+ 想定
- 旧端末・古いブラウザは非対応

### 5.4 OCR 精度
- 「撮影 → 自動入力」を売りにするが、100% の精度は保証しない
- 必ず保存前に内容を確認・修正できる UI を提供

## 6. 用語定義

| 用語 | 意味 |
|---|---|
| 支出 (Expense) | 家計簿上の 1 件の出費。レシート 1 枚 or 手入力 1 回 or 固定費自動計上 1 回 |
| 品目 (Item) | 支出に含まれる個別の商品・項目 |
| カテゴリ (Category) | 品目の分類（食費 / 日用品 等）。標準セット + ユーザー追加 |
| 固定費 (Recurring Expense) | 毎月一定額が発生する費目（家賃 / サブスク / 光熱費の定額部分等） |
| 自動計上 | 固定費テンプレに基づき、月次で支出レコードを自動生成すること |
| ホワイトリスト | `allowed_users` テーブルに登録された利用許可 email リスト |
